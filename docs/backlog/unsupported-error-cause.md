# no linter for an error that names a cause its branch does not show

`if err := connect(addr); err != nil { return errors.New("your password is wrong") }`.

Never run. Rejected in this form. The missing local evidence for a cause is not a contradiction, since a
wrapper may by contract only see authentication failures. The useful part, a stated cause that conflicts
with an explicit known one, joins the branch-polarity item.
