# no linter for marketing or apologetic wording in comments

`// A blazing fast, robust cache.` or `// sorry, ugly hack`.

The prototype (`comment-register`) classified the register of a comment as plain, marketing, apologetic
or machine-sounding. No recorded run produced a finding. Rejected: style, not a claim the code
contradicts. And a word like "hack" often introduces a useful warning.
