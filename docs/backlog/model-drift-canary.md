# nothing notices when a backend model changes under the same name

An endpoint can change behaviour under the same model name, and then tuned thresholds and old cache
entries describe a different classifier. A small versioned set of questions, asked fresh on a schedule
the user sets, could track answer distributions and disagreement. It must not quietly create a paid
recurring job.

Unknown that settles it: whether the returned distributions are stable enough to detect drift, and what
the backends without probabilities would use. No signal does not prove an unchanged model.
